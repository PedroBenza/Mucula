# Identidade linguística Mucula

**Fonte de código:** `js/constants/copy.js`  
**Tom:** angolano, amigável, meio informal, directo, claro — negócio mano a mano. Sem gíria forçada.

## Mapa canónico

| Expressão | Significa |
|-----------|-----------|
| **Feed** | Descobrir o que está disponível |
| **Publicar** | Colocar algo no mercado |
| **Estou à procura** | Dizer o que preciso |
| **Minguito** | Ajuda a encontrar, comparar ou negociar |
| **Fluxo** | Acompanhar o que está a acontecer comigo no mercado |
| **Acompanhar actividade** | Cabeçalho do Fluxo |
| **Interessado** | Demonstrei interesse numa oferta |
| **Negociar** | Estamos a tratar das condições |
| **Acordo confirmado** | As condições foram confirmadas |
| **Combinámos** | Ecrã/resumo de um acordo confirmado |
| **O que procuras já foi publicado.** | Confirmação após publicar uma procura |

## Eliminado

- Em curso (como nome da área) → **Fluxo** / cabeçalho **Acompanhar actividade**
- Combinado (como estado) → **Acordo confirmado**
- Em conversa → **Negociar**

## Regra

Uma ideia, uma expressão. Responder sempre: o que aconteceu, em que estado está, o que posso fazer agora, o que segue.
